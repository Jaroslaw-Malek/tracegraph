About Trace graph

Trace graph is a free network trace files analyser developed for network simulator ns-2 trace processing.

Trace graph can support any trace format if converted to its own or ns-2 trace format.

It runs smoothly under Windows, Linux, UNIX, and Mac OS systems.

Trace converter processes traces over 80x faster.

Supported NS-2 Formats

  • Wired
  • Satellite
  • Wireless (old and new trace)
  • New trace
  • Wired-wireless

Key Features (Version 2.05)

  • 238 2D graphs & 12 3D graphs
  • Delays, jitter, processing times, round trip times, throughput graphs, and statistics
  • Whole network, individual link, and node graphs and statistics
  • All results can be saved to text files; graphs can be exported as JPEG and TIFF
  • X, Y, Z axes statistical data: minimum, mean, maximum, standard deviation, median
  • Plot any graph saved in a text file with 2 or 3 columns
  • Batch processing via script files for automated analysis
