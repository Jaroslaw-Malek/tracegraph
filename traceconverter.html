About Trace converter

Trace converter was developed in Free Pascal to eliminate the conversion bottleneck in Trace graph. While Trace graph relies on Matlab (which is less suited for parsing large, complex trace files), Trace converter streams and parses trace data at native compiled speed.

Performance leap: Trace converter is at least 80x to 180x faster than Trace graph 2.05 / 2.02 (and over 300x faster for traces without IP addresses). A 20MB trace file converts in about one second.

Key architectural benefits:

  • Low memory footprint: Uses optimized file streaming to easily process massive simulation logs.
  • Accurate IP replacement: Targets only valid IP address fields (avoiding false-positive string substitutions like matching packet IDs).
  • One-pass processing: Performs IP extraction and conversion in a single pass, saving 1/3 disk space.
  • Console application: Runs purely in text mode without requiring X-Windows on Linux.

Supported NS-2 Formats

Supports standard formats as well as traces with hexadecimal node numbers and IP addresses:

  • Old wireless
  • New trace
  • Wired-old wireless
  • Wired-new trace
