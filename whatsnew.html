Version 2.05 05/24/2007
Bug Fixes
  • Number of forwarded packets calculations are correct for wireless and wired-wireless trace formats (both old and new trace) [present since 2.03].
  • Number of nodes calculation and node numbers are correct for wireless and wired-wireless trace formats (both old and new trace) with hexadecimal node numbers (fixed issue when >10 nodes) [present since 2.03].
  • Sequence numbers are correctly extracted from -Ps tags for new trace and wired-new trace formats [present since 2.03].
  • Fixed automatic recognition bug for trace formats with IP addresses ("Index exceeds matrix dimensions" message) [present since 1.90b].
Version 2.04 01/09/2006
Performance & New Features
  • Calculations performed after loading trace files with drop events are over 1000x faster (applies to old wireless, new trace, wired-old wireless, wired-new trace, and Trace graph format).
  • Loading time benchmark: post-load calculations for a 20MB new trace file with 20,000 drop events dropped from 170 seconds in v2.03 to just 0.13 seconds in v2.04.
Version 2.03 11/07/2005
Performance Improvements
  • Wired trace files load at least 4.5x (450%) faster.
  • Old wireless trace files load at least 2.2x faster (5.2x faster with hexadecimal node numbers).
  • New trace format files load at least 1.9x faster (3.5x faster with hexadecimal node numbers).
  • Wired-wireless trace files load at least 2x faster (2.2x faster with hexadecimal node numbers).
  • Trace graph format files load at least 3x faster.
  • At least 4x faster IP addresses to node numbers conversion.
  • At least 2x faster searching for IP addresses in trace files (e.g. -ip option).
  • 10x faster constants (e.g. packet types) calculations performed after loading non-.mat trace files.
  • Added new Trace graph file format support with hexadecimal node numbers.
Bug Fixes
  • Fixed automatic IP addresses recognition bug.
  • Trace format of files with line count lower than MAXIMAL NUMBER OF LINES is now recognized properly when AUTOMATIC FORMAT DETECTION is ON.

  • Fixed copying graphs window to clipboard.
